# Ас үйдегі математика

Қазақтың ұлттық тағамдары негізіндегі интерактивті математикалық жинақ: бөлшек, пропорция, пайыз, статистика, тәуелділіктер және геометрия.

Сайт бір файлдан тұрады — `index.html`. Сыртқы кітапханалар мен сервер керек емес, интернетсіз де ашылады.

## GitHub Pages
1. Жаңа репозиторий жасап, `index.html` файлын жүктеңіз.
2. Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.

## Vercel
1. vercel.com → Add New → Project → GitHub репозиторийін таңдаңыз.
2. Framework Preset: **Other**, Build Command бос, Output Directory бос → Deploy.

Пайдаланушы деректері (фото, жазба, таңдаулылар, дастархан жоспары) тек сол құрылғының браузерінде сақталады.
